福彩3D · 排列3 / 使用说明

从一份大底，开始做号。

先选号码范围，再勾选条件，最后统一缩水。两端的计算规则相同，个人方案分别保存在各自设备上。

适用：2026-10-16 界面候选版。下载页所列安装包请以各平台的版本与日期为准。

01 / 第一次使用

  1. 选择彩种。点顶部“福彩3D”或“排列3”，查看数据截止期。联网更新开奖后，再核对期号。
  2. 打开“自己选号”。默认大底为000–999，共1000注；也可以粘贴自己的号码。
  3. 设置条件。在全部条件中点开一类，直接勾选取值；接着点另一类继续设置，手机端不用反复返回。
  4. 统一缩水。点“缩水”，再看保留号码与筛选过程。条件不完整时，先补全提示中的内容。
  5. 复制或保存。复制的是本次计算结果；保存后可到“我的方案”查看或载入。

蓝色表示已选择；“待补全”表示条件还缺参数。取消取值或移除条件后，重新缩水，才能得到新的结果。

02 / 使用自己的大底

“大底”就是本次筛选的起点号码池。打开“大底”，展开“粘贴或自设大底”，填写号码。保留前导零，例如 012 007 461 555。可用空格、换行或逗号分隔。

  • 直选号码：按原来的百、十、个位保留，012与210是不同号码。
  • 组选号码：自动展开所有不同排列并去重，例如012会展开成6注，007展开成3注。
  • 保存大底：输入名称后保存；在已保存列表中直接勾选，当前大底随即切换，已设置的条件继续保留。
  • 转存大底：把当前筛选结果存成新的号码池，下次可在它的基础上继续加条件。
  • 交集：仅保留当前大底与另一份号码池共同包含的直选号码。号码顺序按直选比较。

从别人那里复制的号码，先核对是直选还是组选，再选择对应方式导入。

03 / 条件怎样组合

默认选择“全部满足”时，不同条件同时满足。例如“和值11”加“跨度5”，只保留既是和值11、又是跨度5的号码。同一条条件内勾多个取值，通常表示其中任一个取值符合即可；对子模式等特殊设置以面板文字为准。需要满足任一或至少满足几项时，请看组合方式说明。

和值 / 和尾 / 跨度 / 均值
和值是三位数字相加；和尾是和值的个位；跨度是最大数字减最小数字；均值是和值÷3后四舍五入。例如461：和值11、和尾1、跨度5、均值4。
胆码 / 杀码
胆码要同时设置数字和命中数量，并按面板选择“不同数字”或“出现次数”；重复数字的计数口径不同。杀码排除含有所选数字的号码。
定位选号 / 组选形态
定位分别设置百、十、个位。组六三位各不相同；组三恰好两位相同；豹子三位全相同。
组选两码 / 不定位两码
不要求位置；12表示号码同时含1和2，22需要出现两个2。可选“任一组出现”或“每组都出现”，以当前面板为准。
分解式 / 断组
当前分组要求互不重叠并覆盖0–9。分解式分为两组，保留两组都至少出一个数字的号码；断组分为三组，保留至少有一组完全不出数字的号码。
杀直选复式
分别填写百、十、个位要排除的复式数字，排除三位同时符合的组合。例如百位01、十位2、个位3，排除023与123；不会把所有含0或1的号码都排除。
大小、单双、质合、012路与其他形态
勾选要保留的形态；各类分组与边界以条件面板的说明为准。数值范围可设置最小值和最大值，计算前核对字段名称。

同名条件在其他软件中可能有不同定义。本说明按本工具当前规则编写，不代表与17500或其他软件的所有算法一致。

04 / 跟着做一次：4注筛到1注

  1. 清空之前的筛选条件，进入“大底”，以直选方式填入 012 007 461 555，使用这份大底。
  2. 打开“条件”中的“均值”，勾选4。
  3. 点“缩水”，查看保留号码，应只剩 461。
  4. 再加入“和值11”和“跨度5”，重新缩水，仍然保留461。

三个数字的平均值依次约为1、2.33、3.67、5；四舍五入后为1、2、4、5。

05 / 八栏预测怎么看

点“生成八栏预测”。同一个模型在相同数据截止期和相同数量下，结果相同；重新点按钮不等于随机换号。依据与训练数据范围显示在结果旁。

独胆
提供两个备选数字，开奖中出现其中任一个即符合，不限位置。
双码
开奖中同时出现任一组的两个不同数字，不限位置。
精选 / 直选
其中任一注与开奖号的百、十、个位逐位相同。
四码 / 五码 / 六码
开奖三位数字全部属于对应号码池，可以重复数字。
组三
恰有两个相同数字，按不定位组合比较，不含豹子。

某一栏旁的“缩水”可把这一栏接入自己选号。AI参考与历史表现均不保证未来中奖。

06 / 用历史检验方案

  • 固定方案检验：先保存方案，再选历史区间，比较当前保存的号码与过去开奖是否符合。它不是当时提前发出的预测。
  • AI八栏检验：每一期只用该期开奖之前的数据重新训练，再比较当期结果；同样不等于当时已发布的预测。
  • 遗漏统计：先选彩种和指标，再查看当前遗漏等数据。遗漏只描述历史，不表示接下来一定出现。

号码池越大，符合的历史期数通常越多；比较时要一起看号码数量、规则和随机基准，不能只看命中率。

模拟试机号来自乐彩网，属于非官方模拟数据，与真实开奖分开展示。

07 / 安装、数据更新与程序更新

安卓手机
Android 8.0及以上，保持Android System WebView可用且更新。下载APK后按系统提示安装；升级使用同一签名的安装包，不必先卸载已有应用。
Windows电脑
Windows 10/11 64位，需要Microsoft Edge WebView2。把ZIP完整解压到一个文件夹，再运行其中的EXE。升级先关闭程序，将新版完整解压到新文件夹；不要只取出一个EXE。
开奖更新
在安装后的应用内点“更新开奖”，更新后核对截止期。浏览器界面预览使用内置记录，不能当作实时数据源。
程序更新
电脑与安卓分别下载安装新包。网页更新下载入口不会自动替换你已经安装的程序。方案与大底保存在本设备，暂不跨设备自动同步。

08 / 常见问题

缩水后为什么是0注？

可能是条件冲突，或当前大底没有符合的号码。查看已选条件与缩水过程，逐项修改后重新计算，不必从头录入。

为什么勾选后号码没有立刻变化？

勾选会加入本次条件，最后需要点一次“缩水”，才会计算并更新保留号码。

为什么显示待补全？

有一条已开始设置的条件还缺少数量、分组或位置等参数。补齐它，或移除这条条件，再点缩水。

为什么更新了还是相同预测？

先核对数据截止期。如果截止期和数量相同，模型通常生成同一结果；若数据源暂未提供新一期，点击更新不会凭空产生新开奖。

保存的方案到哪里找？

到“我的方案”查看。手机与电脑分别保存；电脑版“原版研究”的旧方案与新版工作台的方案也分别保存。

组选间距与组合方式

在“间距/范围”中可设置六项组选间距，每项可同时勾选多个数字；空选表示不限。将号码排序成小、中、大：首间距＝小，尾间距＝9－大，第一间距＝小＋9－大，第二间距＝中－小，第三间距＝大－中；组选间距取第一、第二、第三间距的最大值。例如527对应4、2、2、4、3、2。

缩水按钮旁可选择“全部满足”“满足任一”或“至少满足”。大底始终限制号码范围，不参与满足项数；每一行已选条件算一项，一行中的多个取值不拆成多项。没有选择条件时，“全部满足”和“满足任一”保留整个大底；“至少满足”必须有足够的已选条件。

使用新间距或新组合方式的方案会按新版格式保存，请用1.0.1及以后支持该格式的版本打开。旧方案仍按原来的全部满足计算。现有断组仍要求三组不重叠且覆盖0–9；尚未把其他软件的重叠分组口径混入已有方案。

保留所选与排除所选

每行条件可选择处理方式。例如和尾勾选2、5、6：保留所选留下和尾为2、5、6的号码；排除所选删掉这些号码。默认大底1000注时，前者300注，后者700注。

同一行的多个值先按该行完整规则匹配，再整体取反；排除不是把每个值分别做交集。大小单双、两码、均值、数值范围、组选间距和定位也支持。杀码与杀直选复式本身就是排除操作，保留原有含义。

组合方式为全部满足时，每行都要满足。满足任一或至少满足时，排除也作为一行条件参与计数，其他条件通过时该号码仍可能留下；需要所有排除都生效，请用全部满足。固定大底始终限定范围。

空选且未启用的条件不限制号码；已启用但未填写完整的条件会暂停计算。保存包含排除的方案使用新版格式，旧安装包不能读取；请使用1.0.2及以后版本打开，不向旧版本导入。
